## Future capture workflow

1. Record app build/revision and the exact state shown; use an owner-controlled machine and approved pool/session.
2. Capture the unmodified application window. Keep status, units, freshness and limitations visible; do not compose values from separate sessions.
3. Make a copy for privacy review. Remove public wallet/pool/worker identifiers, machine and account names, paths, tokens, session IDs, raw logs and unrelated notifications. Do not alter mining values or state. If anonymization changes visible text, disclose the redaction in caption/alt text.
4. Check legibility at desktop size and narrow/mobile crop. Keep meaningful labels and status; never crop out a stale/unavailable marker or caveat.
5. Retain a private original under the owner’s normal handling policy; publish only the scrubbed copy after confirming it contains no secrets or identifying diagnostics. Record caption, build, capture state and any limitations with the asset.
