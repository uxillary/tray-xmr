## Baseline

Inspected D03D documentation, runtime, source sprite sheet and rendered Home before editing. The 320×144 workshop already uses a tiny 32px, four-pose Squish; walking advanced 8px per tick, tending repeated a six-tick neutral/reach loop, and inspection occurred every 64 ticks. Sprite bobbing moved the feet down during a reach. Crystal shimmer, three conduit lamps and an eight-step wheel were present but faint and independent of gestures. A single cancellable 4–6fps timer and visibility/reduced-motion gates were already sound.

D03D calibration requires 12 distinct stable samples over at least 30 seconds, freezes a session/configuration-local baseline, smooths with alpha .25, clamps ratios to .5–1.5 and uses hysteresis/three-sample dwell. Effect cycles are 4.8/3.6/2.4 seconds. These safeguards are retained.

Activity already translates real backend events and retains only 256 rows in backend order. Its category/timestamp hierarchy was small; Verbose used 12px messages, 10px provenance and 11px expanded context. Reading position/Return to latest already worked. Details had four aligned groups but small labels/explanations and repeated freshness caveats. Diagnostics was a contained native modal with 11px raw output and no section navigation. Intentional Stopped displayed a large “Unavailable” rate plus unavailable pool, time and results. Responsive container layouts existed, with 820px native minimum and narrow zoom reflow; actual 200% zoom/native DPI acceptance was outstanding.

## Implementation decisions

- **Movement:** retain all PNGs, manifests, character proportions and 1× rendering. Starting holds two notice ticks before approaching. Walk in bounded, integer 6px steps with a shorter arrival step, one-pixel upward footfall and an arrival/turn pause. A 96-tick work sequence separates reach/hold/release gestures with unequal observation pauses and a 16px inspection backstep. Backsteps keep Squish facing the crystal; return walks face home. Reach leans one pixel horizontally, keeping the baseline fixed. Rapid retargeting preserves the current position, and Stopped completes its return then cancels scheduling. Controls never wait for animation.
- **Timing/intensity:** 4fps preparation/return; confirmed work retains gentle/steady/lively at 4/5/6fps. The 96-tick work sequence takes 24/19.2/16 seconds, so gesture frequency changes modestly without wider travel. Preparation's 122px approach takes about 5.75 seconds including noticing; a return takes about 5.75 seconds including withdrawal, followed by two turn/settle ticks. Stopped must finish in neutral pose, facing the crystal, before its timer stops. There is still only one frame timer. No artwork was generated or replaced; the four-pose gait remains an artistic limitation.
- **Crystal/machinery:** strengthen the local amber glow and internal stepped shimmer; add a single travelling conduit pixel, with existing lamp phases proportional to the clamped cycle. A short facet/contact highlight follows the actual reach pose. The wheel retains its restrained stepped rotation. Preparation has a static faint facet, with no hashing effects. Effects require confirmed positive work, loaded assets and allowed motion. Hidden/offscreen/reduced-motion scenes stop nonessential animation. No result/reward effects exist.
- **Evidence:** old, invalid, missing and future sample timestamps cannot drive responsive intensity. Home immediately suppresses work for invalid/missing/expired timestamps, preserving the existing five-second evidence timeout for stalled polling. Fresh positive samples without a stable comparison use neutral steady work. Calibration, smoothing, dwell, configuration resets and fixed effect counts remain unchanged. Energy means relative processing pace only.
- **Stopped/Ready:** a quiet “Session stopped” / “Squish is resting. Ready when you are.” presentation replaces the unavailable-rate headline. Ready and setup have their own short prompts. Pool reads “Not connected”, time “Not running”, and absent result counts use a dash. Retained rate is explicitly “Last reported … no live hashrate”; retained time is “Last session”. Failed polling or a real session error suppresses this calm treatment; existing error/recovery and owned Stop controls remain.
- **Console:** Activity has 15px event headings, meaningful icons, 12px categories/times and optional 13px explanations; mining-start context uses only allowlisted actual profile/thread fields. Redundant Info badges are hidden. Verbose has 14px monospace messages, 13px aligned timestamps/categories/provenance/context, two distinct source/kind fields, severity text and wrapped technical values. Copy uses UTC timestamp, source/kind and existing allowlisted context; arbitrary payloads/session IDs/raw configuration remain excluded. Copy feedback reports success/failure.
- **Interaction:** Home/End on the focused stream read oldest/return latest; child disclosures retain their own keyboard behavior. Visible following/older-reading text complements Return to latest and its unread count. A ResizeObserver maintains newest following on viewport resize and disconnects on unmount. The screen-reader keyboard hint is contained within the stream so it cannot create document scrolling. The existing bounded buffer and row-anchor preservation remain; no persistent history or heartbeat events were added.
- **Inspection:** Details uses 16px headings, 13px labels/help and 14px tabular values, plus one explicit reading-source/freshness line. All rate windows, pool/engine/configuration measurements, zero values and contribution disclosures remain. Diagnostics adds focus-moving Startup/Capture/Engine notes navigation, 14px aligned facts, 13px wrapped mono output, guarded copy feedback, Escape cancellation, explicit focus return and captured-element unmount cleanup. Main workspace geometry is unaffected.
- **Accessibility:** retain text lifecycle/freshness/severity, high-contrast focus styles, independently focusable scrolling, reduced-motion composition and crisp sprites. Narrow console/diagnostic rows reflow without shrinking text. Development transition timers now cancel on replay, interruption and unmount.
